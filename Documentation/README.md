# DDoS Attack Detection and Mitigation using Machine Learning

## Overview
Distributed Denial-of-Service (DDoS) attacks pose a major threat to the availability and reliability of online services, often causing severe operational disruptions and financial losses.  
Traditional rule-based detection mechanisms fail to adapt to the evolving nature of these attacks, necessitating **intelligent and scalable solutions**.

This project presents a comprehensive **DDoS attack detection and mitigation framework** leveraging six machine learning models:
- Support Vector Machine (SVM)
- Random Forest (RF)
- Extreme Gradient Boosting (XGBoost)
- K-Nearest Neighbors (KNN)
- Artificial Neural Network (ANN)
- Light Gradient Boosting Machine (LightGBM)

The system is designed to analyze **high-dimensional network traffic data** and accurately classify malicious activity.

---

## Features
- Preprocessing of network traffic datasets for feature extraction.
- Implementation of six ML models for classification.
- Evaluation using **accuracy, precision, recall, and F1-score**.
- Comparative analysis of traditional classifiers vs. boosting-based ensemble models.
- Scalable design for potential **real-time DDoS mitigation**.
